# Three Card Poker 

## Overview
This is a console-based Three Card Poker game written in Java. Players can place bets, receive random hands, and compete against a dealer. The game includes logic for comparing hands, tracking wins/losses, and managing betting history using a stack.

## Features
- Random hand generation for player and dealer
- Hand evaluation (pair, flush, straight, etc.)
- Betting system with starting balance
- Stack used to track previous hands and outcomes

## How to Run
1. Clone the repository
2. Open the project in an IDE like IntelliJ or Eclipse
3. Run `Main.java`

## Technologies Used
- Java
- Object-Oriented Programming
- Stack data structure
